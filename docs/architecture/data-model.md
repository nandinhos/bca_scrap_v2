# Dados e propriedade

| Dado | Proprietário | Regra |
|---|---|---|
| Configuração da OM, SAD e usuários | Instalação local | Uma OM por banco; não importar nem administrar uma segunda OM. |
| Efetivo, SARAM, e-mail e ocorrências | OM local | Permanecem autenticados, auditáveis e incluídos em backup, mesmo quando o BCA for ostensivo. |
| BCA/PDF e texto extraído | OM local | Cópia local para acesso rápido na intranet; integridade da origem e retenção precisam ser controladas. |
| Palavras-chave | Configuração institucional da OM | Definir se são globais da OM ou pessoais; não manter semântica ambígua. |

O banco atual contém campos para múltiplas OMs. A decisão é de implantação e produto; o código deve ganhar uma invariável explícita que rejeite segunda OM em produção.
